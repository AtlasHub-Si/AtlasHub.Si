# Como contribuir
Use uma issue para propor uma melhoria documental ou um projeto educativo. Descreva problema, resultado esperado e limites. Não inclua dados de clientes, credenciais, documentos pessoais ou pedidos de investimento.

Antes de realizar trabalho significativo, combine o escopo e os direitos de utilização. A contribuição pontual não concede ações, salário, vínculo profissional ou prioridade de contratação. Trabalho produtivo para clientes e operação deve ter a relação e remuneração devidas formalizadas.

Pull requests devem identificar fontes, autoria e licença de materiais externos. A equipa pode recusar propostas sem autorização de uso ou capacidade de manutenção.

Não há obrigação de contribuir para obter ou manter direitos legais de um eventual investimento.
