# Código de conduta
Respeitar participantes e diferenças de experiência. Não praticar assédio, discriminação, fraude, exposição de dados pessoais ou publicidade enganosa.

Discutir ideias e evidências. Identificar conteúdo gerado por IA quando isso for relevante para avaliar autoria ou fiabilidade. Não usar a comunidade para vender investimentos ou prometer rendimentos.

Reportar violações em privado para contact@atlashub.si. A moderação deve ouvir as partes, preservar informação necessária e aplicar medidas proporcionais, incluindo remoção de conteúdo ou restrição de acesso conforme os termos aplicáveis.
