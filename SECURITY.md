# Segurança
Não publique vulnerabilidades, tokens, passwords ou dados pessoais numa issue. Reporte para contact@atlashub.si com descrição e passos mínimos, sem explorar ou obter dados desnecessários.

O contacto não é um programa de recompensas nem autorização para testes intrusivos. Não há prazo de resposta garantido publicado neste momento.

As permissões, os backups e os fornecedores são tratados na operação privada. Este repositório não contém configurações ou credenciais de produção.
